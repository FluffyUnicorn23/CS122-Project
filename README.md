High Level Project Description:

We created a PID ball gimble. A laser sensor measures the distance from the ball. The servo motor will then tilt the seesaw until
the ball is in the desired position. This distance is graphed and displayed on the RGB LCD.

Elements of Complexity:

1. PID control
2. Sending graphical information to FPGA

User Guide:

The user can place a ball on the seesaw, and move it around. The user can also hit a button to change the balls desired position.

Hardware Components:

1. Laser sensor
2. servo motor
3. button
4. Seesaw
5. RGB LCD
6. Raspberry Pi Pico 2W
7. ICESugar Pro FPGA

Software Components:

1. <servo.h>
